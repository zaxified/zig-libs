# p521

**NIST P-521 (secp521r1), the curve Zig 0.16's std does not ship.** std has P-256 and
P-384; every P-521 feature in this collection — ssh `ecdh-sha2-nistp521` /
`ecdsa-sha2-nistp521`, jwt `ES512`, x509 P-521 certificates, hpke DHKEM(P-521),
acme — was refused for lack of a curve. This module provides the field, the group, ECDH
and ECDSA-P521 (RFC 6979), with the API shape of `std.crypto.ecc.P384` and
`std.crypto.sign.ecdsa.EcdsaP384Sha384`, so a consumer swaps a type.

- **Model after:** std's `P384` / `Ecdsa` (API); FIPS 186-5, SP 800-186, SEC 1,
  RFC 6979 (algorithms); OpenSSL `ecp_nistp521` as the differential oracle.
- **Platform:** any (portable Zig, no asm). **Role:** crypto primitive.
  **Concurrency:** reentrant. **Deps:** `entropy` (fail-closed key generation).

Provenance: original work of the zig-libs authors (MIT), written from the public
standards. Test data: NIST CAVP (US Government work), Wycheproof (Apache-2.0, see
`NOTICE`), RFC 6979 A.2.7, and OpenSSL output generated by `tools/openssl_oracle.py`.
See `SPEC.md`.

## Usage

```zig
const p521 = @import("p521");
const Ecdsa = p521.EcdsaP521Sha512;

// Keys and signatures (dead-stack-clean forms: *Into, pointers in).
var kp: Ecdsa.KeyPair = undefined;
Ecdsa.KeyPair.generateInto(&kp, io);
defer std.crypto.secureZero(u8, std.mem.asBytes(&kp));

const sig = try kp.sign("message", null);          // RFC 6979 deterministic
try sig.verify("message", kp.public_key);
var der_buf: [Ecdsa.Signature.der_encoded_length_max]u8 = undefined;
const der = sig.toDer(&der_buf);                     // strict DER, ≤ 139 bytes
const pk = try Ecdsa.PublicKey.fromSec1(&kp.public_key.toUncompressedSec1());

// ECDH: x-coordinate of secret · peer, 66 bytes; compressed or uncompressed peer.
var shared: [66]u8 = undefined;
try p521.ecdhInto(&shared, &kp.secret_key.bytes, peer_sec1);
defer std.crypto.secureZero(u8, &shared);
```

## API

```zig
pub const Fe;                        // GF(2^521 − 1), 66-byte encoding
pub const Scalar;                    // Z/nZ (Montgomery), std scalar shape
pub const scalar;                    // encoded_length = 66, CompressedScalar, add/mul/…
pub const P521 = struct {            // std P384's surface, 66-byte scalars
    basePoint, identityElement, B, Fe, scalar,
    fromSec1, toCompressedSec1 ([67]u8), toUncompressedSec1 ([133]u8),
    fromAffineCoordinates, fromSerializedAffineCoordinates, affineCoordinates, recoverY,
    add, addMixed, sub, subMixed, dbl, neg, equivalent, rejectIdentity, random,
    mul(p, s: [66]u8, endian),       // constant time
    mulInto(out, p, s: *const [66]u8, endian),
    mulPublic, mulDoubleBasePublic,  // VARIABLE TIME, public scalars only
};
pub fn ecdh(secret: [66]u8, peer_sec1: []const u8) EcdhError![66]u8;
pub fn ecdhInto(out: *[66]u8, secret: *const [66]u8, peer_sec1: []const u8) EcdhError!void;
pub const EcdsaP521Sha512 = Ecdsa(Sha512);
pub fn Ecdsa(comptime Hash: type) type;   // KeyPair, SecretKey, PublicKey, Signature,
                                          // Signer, Verifier — std's surface
```

`KeyPair` methods take `*const KeyPair`; every secret path is burned and has a
pointer/`out` twin (`generateDeterministicInto`, `fromSecretKeyInto`,
`signPrehashedInto`, `signerInto`). Differences from std's `Ecdsa` are listed in
`SPEC.md` § Algorithm.

## Verification

`zig build test-p521` runs NIST CAVP (SigVer 75, SigGen 60, KeyPair 10, PKV 12,
CDH 25), Wycheproof (ECDSA DER 542, P1363 304, ECDH 669), RFC 6979 A.2.7, the
OpenSSL oracle (24 keys), field/scalar wide-integer differentials, and the
fuzz-harness reach test. Fuzz verdict: `P521_FUZZ=<runs>[,<seed>]` on the
ReleaseSafe test binary. Constant time: `scripts/checks/ctgrind.sh p521`.
Bench: `P521_BENCH=1 zig build test-p521 -Doptimize=ReleaseFast`.
