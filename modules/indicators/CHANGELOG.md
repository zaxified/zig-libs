- **2026-11-15** — **BEHAVIOURAL (module is new, unreleased):** batch `max`, `min` and `minmax` now run TA-Lib 0.8.3's Van Herk block scan (`window.extBatch`, no scratch: the block's suffix extrema are parked in the output slots it is about to fill) instead of the per-bar automaton, so the sign of a 0.0 / -0.0 tie, and where a NaN shows, equal the C batch; the oracle found the difference on its new tie inputs (kind 3: blocks of +0 / -0 / 3 / -3, also MAXINDEX, MININDEX, MINMAXINDEX; zero signs compared) and is now bitwise equal on them.
