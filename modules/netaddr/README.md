# netaddr

IP address parse/format + **RFC 6724** destination/source address selection,
CIDR/prefix math, and the Go `net/netip` + `go4.org/netipx` surface (zones,
`AddrPort`, ordering, `IpRange`, `IpSet`).

- Clean-room from RFC 6724, covering the full destination rule set.
- **Model after:** Go `net/addrselect.go` + glibc `getaddrinfo` (UDP-connect
  route-probe trick). Policy table and rule coverage match Go row-for-row.
- **Why:** RFC 6724 selection ("several candidate addresses for a dual-stack
  host — which do I connect to, in what order") is a real gap in Zig std;
  foundational for `http`, `dns`, `icmp`.
- **Platform:** any (pure logic; only `systemSource` is Linux-only).
  **Role:** util. **Concurrency:** reentrant (no shared state).
  **Allocation:** none in the scalar API — every parse and format works on a
  caller buffer. ⚠ `summarize`, `mergePrefixes`, `IpRange.prefixes` and the
  `IpSet`/`IpSetBuilder` family DO allocate (caller-passed allocator). The first two return
  a slice of prefixes and take an allocator to build it. The bound is
  `2·width − 2` prefixes for a single range (62 for IPv4, 254 for IPv6),
  which is the standard result for a range-to-prefix decomposition.
  Corrected 2026-09-04 — it said "none, anywhere".

Provenance: clean-room from RFC 6724 and RFC 5952; cross-checked against Go
`net/addrselect` (BSD-3-Clause, The Go Authors) and the glibc `getaddrinfo`
algorithm. The CIDR/prefix operations (`Prefix`, `summarize`, `mergePrefixes`)
model after Go `net/netip.Prefix` (BSD-3-Clause) and `go4.org/netipx`
(BSD-3-Clause) — behavior only, clean-room, no source consulted or copied. No
fping code is involved — an earlier note claiming otherwise was a bookkeeping
error. DATA: `src/rfc6724_vectors.zig` holds the destination orders glibc 2.43
`getaddrinfo` and the IPv6 sources Linux 7.0 chose on this machine, and
`src/parse_vectors.zig` the verdicts and texts of glibc `inet_pton`/`inet_ntop`
and Python 3.14 `ipaddress`, `src/netip_vectors.zig` the answers of Go 1.26
`net/netip` and `go4.org/netipx` — all generated by our own tooling
(`tools/rfc6724_oracle.py`, `tools/parse_oracle.py`,
`tools/go_netip_oracle`) over our own cases, the
foreign implementations run as black-box oracles: observed behaviour, exempt
per root `NOTICE` §0; no third-party corpus is reproduced.

## API

```zig
const netaddr = @import("netaddr");

// Parse / format (RFC 5952 canonical for v6, no panics on bad input)
const ip = netaddr.parseIp("2001:db8::1").?;      // ?Ip — .{ .v4, .v6 }
var buf: [netaddr.max_ip_text_len]u8 = undefined;
const text = netaddr.formatIp(ip, &buf);           // "2001:db8::1"
const hp = netaddr.parseHostPort("[::1]:8080").?;  // .{ .host = "::1", .port = 8080 }

// Address-space predicates (RFC 1918/4193/3927/…)
_ = ip.isPrivate();          // 10/8, 172.16/12, 192.168/16 — v4-mapped unwrapped
_ = ip.isUniqueLocal();      // fc00::/7, the v6 analogue
_ = ip.isLoopback();
_ = ip.isLinkLocalUnicast();
// Composing these into "safe to connect to" is policy, not addressing — see
// `rdap`'s SSRF guard for a worked example.

// RFC 6724 classification
_ = netaddr.scopeOf(ip);        // Scope (RFC 4007-valued enum)
_ = netaddr.precedenceOf(ip);   // policy-table precedence (higher = preferred)
_ = netaddr.labelOf(ip);        // policy-table label
_ = netaddr.commonPrefixLen(a, b);

// Destination ordering (what glibc getaddrinfo does before connect)
netaddr.sortDestinations(addrs, netaddr.systemSource); // Linux route probe
netaddr.sortDestinationsWithSources(addrs, srcs);      // pure, testable core

// Source selection (RFC 6724 §5, common rules)
_ = netaddr.selectSource(host_addrs, dst);

// Go net/netip parity
_ = ip.compare(other);               // v4 before v6, then numeric (Addr.Compare)
_ = ip.next(); _ = ip.prev();        // ?Ip, null at the family's ends
_ = ip.isGlobalUnicast();            // + isLinkLocalMulticast, isInterfaceLocalMulticast
_ = ip.prefix(24);                   // ?Prefix, masked (Addr.Prefix)
_ = netaddr.formatIpExpanded(ip, &ebuf);           // "2001:0db8:0000:…" (StringExpanded)
const z = netaddr.parseIpZoned("fe80::1%eth0").?;  // ZonedIp{ ip, zone } (ParseAddr)
const ap = netaddr.parseAddrPort("[fe80::1%eth0]:443").?; // AddrPort (ParseAddrPort)
const sa = try ap.toStd();           // std.Io.net.IpAddress (numeric zone → interface)
_ = netaddr.AddrPort.fromStd(sa);
std.debug.print("{f} {f}\n", .{ ip, ap });  // every value type has `format`

// go4.org/netipx parity
const r = netaddr.parseIpRange("10.0.0.5-10.0.0.20").?;   // IpRange: contains/overlaps/toPrefix/prefixes
var b: netaddr.IpSetBuilder = .empty;                      // add/remove addr/prefix/range/set,
defer b.deinit(gpa);                                       // complement, intersect, clone
try b.addPrefix(gpa, netaddr.parsePrefix("10.0.0.0/8").?);
try b.removeRange(gpa, r);
var set = try b.toSet(gpa);                                // IpSet: binary-search contains,
defer set.deinit(gpa);                                     // containsPrefix/Range, overlaps*,
_ = set.contains(ip);                                      // eql, ranges, prefixes,
_ = try set.removeFreePrefix(gpa, 24);                     // removeFreePrefix
```

## Notes / deviations

- `sortDestinations` implements RFC 6724 §6 rules 1, 2, 5, 6, 8, 9 — the same
  subset as Go. Rules 3/4/7 need OS state (deprecation, home addresses,
  transport nativeness) nobody tracks. Rule 9 (longest matching prefix) is
  IPv6-only, matching Go (see Go issues 13283/18518).
- `selectSource` implements §5 rules 1, 2, 6, 8; rules 3/4/5/7 need
  per-interface OS state and are documented corners (glibc has the same).
- `Scope` is a numeric-backed non-exhaustive enum so unnamed multicast scope
  nibbles order correctly, mirroring Go's `classifyScope`.
- Zones: `Ip` stays zone-less (it is the substrate ~20 modules switch on);
  `parseIpZoned` / `ZonedIp` / `AddrPort` carry the zone beside it, stored
  inline (≤ `max_zone_len` = 31 bytes — Go takes any length; a kernel never
  needs more than 15 for a name or 10 for an index). `parseIp*` still reject a
  zone; `parseHostPort` passes it through in `host` untouched.
- Divergences from Go, on purpose: `parseAddrPort` refuses a port with a
  leading zero (`:080`; this module's port rule, the F8 decision); `IpSet` /
  `IpSetBuilder` report a malformed `IpRange` at the call instead of
  accumulating errors; `removeFreePrefix` only picks a prefix whose family can
  hold the requested length (netipx can pick a v4 one for `/64` and return an
  invalid prefix with ok = true) and returns null for a length past 128.
- `Ip.isPrivate` covers only RFC 1918; Go's `IsPrivate` also counts
  `fc00::/7`, which here is `isUniqueLocal`.
