# `latency-stats` verification instruments

| tool | role |
|---|---|
| `bench.zig` | `zig build bench-latency-stats [-Djcc-safe] [-- --ref=c\|rust\|go --alt=c\|rust\|go\|none] [workload ...]`: the `Histogram` against HdrHistogram_c 0.11.10, `hdrhistogram` 7.6.0 (Rust) and `hdrhistogram-go` v1.4.0 on six workloads (`record`, `record_corrected`, `percentiles`, `merge`, `merge_empty`, `mean_stddev`; what one op does is in the header of `bench.zig` and `c_bench/foreign_bench.c`). Before timing it runs a wire interop gate: C and Go decode our compressed V2 histogram to exactly our counts, and we decode theirs. It is the program behind the card's `**Performance:**` line. |
| `c_bench/foreign_bench.c` | the C side (and the C half of the interop gate), compiled by `bench.zig` against the release tarball. |
| `rust_bench/` | the Rust side (`Cargo.toml` pins `hdrhistogram =7.6.0`, default features off, so only `byteorder` and `num-traits` come with it). |
| `go_bench/` | the Go side (and the Go half of the interop gate); `go.mod` pins `hdrhistogram-go` v1.4.0. |

## One-time setup

HdrHistogram_c is not vendored (CC0 / BSD-2-Clause). Unpack the pinned release where `bench.zig` looks for it
(or point `HDRHISTOGRAM_C_DIR` elsewhere):

```bash
mkdir -p .zig-cache/hdrhistogram-c-0.11.10
curl -sL https://github.com/HdrHistogram/HdrHistogram_c/archive/refs/tags/0.11.10.tar.gz -o .zig-cache/hdrhistogram-c.tgz
sha256sum .zig-cache/hdrhistogram-c.tgz   # c3b06d077e680d112abf9f027d8a558f1176ee4a55a7c523577833391d8c2249
tar xzf .zig-cache/hdrhistogram-c.tgz -C .zig-cache/hdrhistogram-c-0.11.10 --strip-components=1
(cd modules/latency-stats/tools/go_bench && go mod download)    # fills the module cache; the build runs with GOPROXY=off
(cd modules/latency-stats/tools/rust_bench && cargo fetch --locked)   # the build runs with --offline
```

Needs `cc` with zlib headers (for HdrHistogram_c's compressed log), go 1.26, cargo. Run from the repository root.

## Provenance

`go_bench/go.mod` and `go.sum` and `rust_bench/Cargo.lock` were generated on 2026-11-02 (`go mod tidy`,
`cargo generate-lockfile`) against the versions named above, both MIT (or MIT OR Apache-2.0) per their licence files;
`go.sum` lists the upstream's test-only dependencies as `go mod tidy` writes it, none of which the build uses. No
foreign data file is committed. The values the bench records are generated by `bench.zig` from a fixed seed.
