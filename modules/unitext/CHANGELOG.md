# unitext — changelog

Newest first. See the root [`CHANGELOG.md`](../../CHANGELOG.md) for which
release tag each entry shipped in, and `CONVENTIONS.md` §8 for the policy.

## Unreleased

- **2026-11-13** — **CHANGED:** tables moved from Unicode 17.0.0 to **18.0.0** (`unicode_version`): 13,007 newly assigned code points, new case pairs (U+0277 ɷ, U+027C ɼ, U+AB4B ꭋ, U+AB4C ꭌ now uppercase to U+A7DD, U+A7E2, U+AB6C, U+AB6D; 16 new Latin Extended-G pairs), U+1DF95 (folds to ß / `ss`, uppercases to `SS`), two Unihan numerals now `isNumeric`; `unaccent` gains 25 letters and 2 expansions of 18.0 by the same name rules (a Latin ligature `WITH` a second letter is no longer read as a letter with a mark). Vectors: NormalizationTest.txt 18.0.0; CPython 16.0 answers kept on the code points identical in 16.0, 17.0 and 18.0 (`tools/py_oracle.py --ucd` repeated); Rust 17.0 answers kept except the 41 code points whose case mapping changed (`tools/restrict_vectors.py`).
- **2026-11-13** — **CHANGED:** `unaccent` folds the Latin letters whose UCD name is not `<X> WITH …` as ICU's Latin-ASCII does: ŋ Ŋ → n N, ĸ → q, ſ → s, ɛ → e, ʉ → u, ɡ → g, the insular and other glyph variants, the small capitals (ᴀ → A) and a named base under `WITH` modifiers (ɟ → j); with `expand_ligatures` also the medievalist ligature letters (Ꜳ → AA, ꝏ → oo, ƕ → hv, ƣ → oi, ᵫ → ue) and the IPA digraphs (ʦ → ts, ȸ → db). The lists stay derived from UCD names by the generator (238 → 304 letters, 29 → 67 expansions). **NEW:** `tools/latin_ascii_diff.py`, a differential oracle that runs every Latin code point through `uconv -x Latin-ASCII` and classifies each difference; letters left on purpose (ɧ, the abbreviation letters ꝱ…ꝷ, ŉ, fullwidth forms) are named in SPEC.
- **2026-11-10** — **NEW:** `isAlphabeticCp` / `isAlphabetic`, the Alphabetic derived property (L + Nl + Other_Alphabetic: Rust `char::is_alphabetic`, polars `cs.alpha()`; combining vowel signs such as U+0903 count, U+00B2 and U+0301 do not), one more `gcflags` bit (+132 B of tables); checked for every code point against `DerivedCoreProperties.txt` (`src/testdata/alphabetic_ranges.txt`). **CHANGED:** `unaccent` with `expand_ligatures` (default) now expands the twelve Latin digraph letters U+01C4-01CC and U+01F1-01F3 to DZ/Dz/dz, LJ/Lj/lj, NJ/Nj/nj as ICU's Latin-ASCII does (they stayed as they were before).
- **2026-11-09** — **FIXED:** `unaccent` folded the titlecase digraphs U+01C5 Dž, U+01C8 Lj, U+01CB Nj, U+01F2 Dz to one ASCII letter and dropped the second; they now stay as they are (the generator's name rule no longer matches a name containing a second `LETTER`; 238 letters). Independent review and no-panic sweep of the module found nothing else.
- **2026-11-09** — **NO CONSUMER-VISIBLE CHANGE:** SPEC Backlog: the `Alphabetic` derived property (`isAlphabeticCp`), asked for by `dataframe`'s polars-style selectors.
- **2026-11-09** — **NEW:** consumer example `example/main.zig` (CONVENTIONS 7.2: 70 `pub fn`): an accent- and case-insensitive search key, `upper` of `ß`, field validation, `lowerTo` into a fixed buffer, the ill-formed-UTF-8 policies; `zig build run-example-unitext`.
- **2026-11-09** — **NEW MODULE:** `unitext` — Unicode 17.0.0 text algorithms on UTF-8: full case mapping (`lower` / `upper` / `title` / `capitalize` / `swapcase` / `casefold`, CPython `str` semantics, Final_Sigma, SpecialCasing; Rust's `to_lowercase` / `to_uppercase` agree on every scalar value), normalization (`normalize` NFC / NFD / NFKC / NFKD, `quickCheck`, `isNormalized`), `unaccent` (NFD, drop nonspacing marks, NFC, plus the letters without decomposition: ł ø đ ħ ŧ ı ŀ …, and `expand_ligatures`: æ œ ß þ ﬁ …), Python `str` classification (`isAlpha` … `isAscii`) and per-code-point properties; ill-formed UTF-8 is a policy (`reject` / `replace` / `pass_through`); allocating and writer forms, `max_output` / `max_segment` caps. Verified against Unicode's `NormalizationTest.txt` (all parts), 12,069 range lines + 2,000 strings of CPython 3.14.4 answers (`tools/py_oracle.py`), and Rust 1.93 `to_lowercase` / `to_uppercase` over every scalar value (`tools/rust_case.rs`); tables generated by `tools/ucd_gen/gen.py`.
