# p384

**NIST P-384 (secp384r1), 2.7–8× faster than Zig std's, constant time on every secret path.**
std ships P-384, but its generic ladder made jwt `ES384` 4.2× slower to sign than golang-jwt and
a TLS client's P-384 key share ~1 ms. This module is `p521`'s sibling over a 384-bit Montgomery
field — field, group, ECDH and ECDSA-P384 (RFC 6979) with the API shape of
`std.crypto.ecc.P384` and `std.crypto.sign.ecdsa.EcdsaP384Sha384`, so a consumer swaps a type.
On amd64 with ADX/BMI2 the field multiply is a `MULX`/`ADCX`/`ADOX` core; elsewhere portable Zig.

- **Model after:** std's `P384` / `Ecdsa` (API); FIPS 186-5, SP 800-186, SEC 1, RFC 6979
  (algorithms); OpenSSL as the differential oracle.
- **Platform:** any (portable; amd64 ADX/BMI2 asm for the field multiply). **Role:** crypto
  primitive. **Concurrency:** reentrant. **Deps:** `entropy` (fail-closed key generation).

Provenance: original work of the zig-libs authors (MIT), written from the public standards. Test
data: NIST CAVP (US Government work), Wycheproof (Apache-2.0, see `NOTICE`), RFC 6979 A.2.6, and
OpenSSL output generated by `tools/openssl_oracle.py`. See `SPEC.md`.

## Usage

```zig
const p384 = @import("p384");
const Ecdsa = p384.EcdsaP384Sha384;

// Keys and signatures (dead-stack-clean forms: *Into, pointers in).
var kp: Ecdsa.KeyPair = undefined;
Ecdsa.KeyPair.generateInto(&kp, io);
defer std.crypto.secureZero(u8, std.mem.asBytes(&kp));

const sig = try kp.sign("message", null);          // RFC 6979 deterministic
try sig.verify("message", kp.public_key);
var der_buf: [Ecdsa.Signature.der_encoded_length_max]u8 = undefined;
const der = sig.toDer(&der_buf);                     // strict DER, ≤ 104 bytes
const pk = try Ecdsa.PublicKey.fromSec1(&kp.public_key.toUncompressedSec1());

// ECDH: x-coordinate of secret · peer, 48 bytes; compressed or uncompressed peer.
var shared: [48]u8 = undefined;
try p384.ecdhInto(&shared, &kp.secret_key.bytes, peer_sec1);
defer std.crypto.secureZero(u8, &shared);
```

## API

```zig
pub const Fe;                        // GF(p), Montgomery limbs = std P384.Fe's; 48-byte encoding
pub const Scalar;                    // Z/nZ (Montgomery), std scalar shape
pub const scalar;                    // encoded_length = 48, CompressedScalar, add/mul/…
pub const P384 = struct {            // std P384's surface
    basePoint, identityElement, B, Fe, scalar,
    fromSec1, toCompressedSec1 ([49]u8), toUncompressedSec1 ([97]u8),
    fromAffineCoordinates, fromSerializedAffineCoordinates, affineCoordinates, recoverY,
    add, addMixed, sub, subMixed, dbl, neg, equivalent, rejectIdentity, random,
    mul(p, s: [48]u8, endian),       // constant time
    mulInto(out, p, s: *const [48]u8, endian),
    mulPublic, mulDoubleBasePublic,  // VARIABLE TIME, public scalars only
};
pub fn ecdh(secret: [48]u8, peer_sec1: []const u8) EcdhError![48]u8;
pub fn ecdhInto(out: *[48]u8, secret: *const [48]u8, peer_sec1: []const u8) EcdhError!void;
pub const EcdsaP384Sha384 = Ecdsa(Sha384);
pub fn Ecdsa(comptime Hash: type) type;   // any digest ≤ 64 bytes (bits2int truncation);
                                          // KeyPair, SecretKey, PublicKey, Signature,
                                          // Signer, Verifier — std's surface
```

`KeyPair` methods take `*const KeyPair`; every secret path is burned and has a pointer/`out`
twin. Differences from std's `Ecdsa` (RFC 6979 nonces exactly, strict DER, range checks up front)
are listed in `SPEC.md` § Algorithm.

## Performance

i7-7920HQ, ReleaseFast, 2026-10-13 (`SPEC.md` § Performance): ECDH 423 µs, sign 157 µs, verify
500 µs — 0.95–1.00×, 0.61×, 0.83× OpenSSL 3.5.5; 0.37×, 0.12×, 0.21× std's `P384`.

## Verification

`zig build test-p384` runs NIST CAVP (SigVer 75, SigGen 60, KeyPair 10, PKV 12, CDH 25),
Wycheproof (ECDSA SHA-384 DER 504 / P1363 261, SHA-512 DER 542 / P1363 299, ECDH 798), RFC 6979
A.2.6, the OpenSSL oracle (24 keys), the mutation-audit tests, field/scalar wide-integer
differentials, asm = portable, and the fuzz-harness reach test. Fuzz verdict:
`P384_FUZZ=<runs>[,<seed>]` on the ReleaseSafe test binary. Constant time:
`scripts/checks/ctgrind.sh p384`. Bench: `P384_BENCH=1 zig build test-p384 -Doptimize=ReleaseFast`.
