# b64ct

Constant-time base64 for secrets: private keys in PEM, shared secrets in
config files (`secret "…";`), `AUTH PLAIN` credentials, exported session keys.
`std.base64` looks every secret sextet and every secret character up in a
table — a load address a cache-timing attacker can read. Here each character
is computed with masks only, no table and no branch on the data, and the
verdict on an input is taken once, at the end.

The four RFC 4648 variants (`standard`, `standard_no_pad`, `url_safe`,
`url_safe_no_pad`), with libsodium's decoder contract — the same strictness,
an ignore set, a prefix mode — plus PEM/MIME line wrapping, allocating
helpers and in-place decoding. 3–17× faster than libsodium's constant-time
codec on x86-64 (16 characters per step on the decode side).

- **Model after:** libsodium `sodium_bin2base64` / `sodium_base642bin` (C, the
  reference: variants, strictness, `ignore`, `b64_end`); RustCrypto `base64ct`
  (Rust: line wrapping, `decode_in_place`).
- **Platform:** any (pure computation; the 16-lane path is little-endian
  only, big-endian targets take the scalar path). **Role:** codec.
  **Concurrency:** reentrant. **Allocation:** none, except `encodeAlloc` /
  `decodeAlloc`.

## API

```zig
const b64ct = @import("b64ct");
const C = b64ct.standard; // or .standard_no_pad, .url_safe, .url_safe_no_pad

// encode: lengths are public, octets are not
var buf: [C.encodedLen(32)]u8 = undefined;
const text = C.encode(&buf, &key);                    // byte-identical to std
const pem = C.encodeWrapped(&pem_buf, der, 64, .lf);  // PEM body, every line ends in \n

// decode: the exact canonical encodings, as libsodium and std accept them
var out: [32]u8 = undefined;
const k = try C.decode(&out, text);                   // error.InvalidCharacter / InvalidPadding / NoSpaceLeft
const d = try C.decodeIgnoring(&der_buf, pem_body, b64ct.pem_whitespace);
const p = try C.decodePrefix(&der_buf, text_with_trailer, "\n"); // p.data, p.consumed (libsodium's b64_end)
const inplace = try C.decodeInPlace(text_buf);

const owned = try C.decodeAlloc(gpa, text);           // exact length
```

On any decode error nothing derived from the input is left in `out` (in
place, the undecoded text is the caller's input and stays). `encode` and
`encodeWrapped` panic in every build mode when `out` is too short — std's
encoder only asserts, which ReleaseFast drops; `encodeWrapped`'s `line_len` is
comptime and checked to be a positive multiple of 4.

## What is public

The lengths, the number of `=`, which characters an ignore set skipped, where
`decodePrefix` stops, and the accept/reject verdict — each turned into a branch
at one place (`public` in `src/root.zig`), and `decodeIgnoring`/`decodePrefix`
additionally reveal where a rejected text's first bad character stands, as
libsodium's do. `decode` reveals nothing else. Machine-checked by
`scripts/checks/ctgrind.sh b64ct`; `SPEC.md` § Constant-time contract has the
details.

## Error kinds

std's errors (`std.base64.Error`), so a caller can switch over. Unpadded
variants return exactly std's error for every input; padded variants agree with
std on accept/reject and the bytes, but not always on which error — std names
the first fault by position, which a decoder that does not branch per
character cannot (`SPEC.md` § Wire format).

Provenance: original work of the zig-libs authors (MIT), from the per-module
copies in `acme`, `dns`, `smtp` and `megolm` (2026-10-10..16) that this module
replaces. The decoder's contract (strictness, `ignore`, `b64_end`) is
libsodium's — a **design reference**, studied in its `codecs.c` (ISC licence),
no source copied; the arithmetic is our own. `tools/` drives libsodium 1.0.22's
`codecs.c` as a black-box oracle and benchmark; it is fetched, never committed. No data is committed: the C files and headers in `tools/` (`sodium_oracle.c`,
`c_bench/sodium_bench.c`, `sodium_shim/`) are our own source, and every test
vector is RFC 4648's or generated by our own tooling at run time.
